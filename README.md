# 🏎️ Online Karting Game

**Multiplayer race game made with unity 6 and photon fusion 2.**

---

## About the Project

Karting Game is a multiplayer 3D racing experience built with Unity, showcasing smooth gameplay, scalable systems, and robust networking.
Using Photon Fusion 2, the game supports synchronized online play with a matchmaking system that connects players seamlessly.

Beyond just being fun to play, this project demonstrates my ability to design and implement:

Physics-based vehicle controllers

Modular UI systems adaptable to different modes

Extensible game mode architecture

Multiplayer networking and synchronization

The result is a project that highlights both gameplay design and software engineering practices, making it easy to extend with new tracks, rules, or features.

Sounds still in progress(i am not sound producer) there are system like crossfading and etc. but sounds not set up well yet.

---

##  Features

 Two Playable Racing Tracks – Each with unique layouts to test driving skills.

 Points & Ranking System – Winner is determined after all races, encouraging competitive play.

 Scalable Game Mode Architecture – Easily extendable for adding new race modes or rules.

 Modular UI – Clean, flexible interface that adapts to different game modes.

 Customizable Kart Controller – Highly tunable handling and physics for different kart setups.

 Surface System – Karts react differently depending on the track surface, adding depth to driving mechanics.

 After-Race Cutscene (Work in Progress) – Displays results with performance rankings.

 Engaging Main Menu – Unusual approach to navigation.

 Matchmaking System - Simple matchmaking which allows to fill lobbies and automatically start game including all the quit, connection lost, etc issues handled.

 Post Effects - Fullscreen outline, cel shading(not currently in use cause of low poly models), volumetric fog and a lot more.

 Customizable Minimap - Simple minimap with networked icons which is done by screenshoting entire scene and rescaling into ui size.
